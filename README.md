# SRE Agent Wine Demo

This workspace contains a lightweight demo application for an SRE agent focused on a luxury wine wholesale scenario.

## Components
- Backend: Spring Boot 2.7 / Java 8 / Maven
- Frontend: Vue 3 + Vite
- Data: in-memory H2 for local development

## Run locally

### Backend
```bash
cd backend
mvn spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000
